# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-21

Первая публичная версия.

### Добавлено

- Двусторонний обмен: канал Lolka ↔ сессия OpenClaw (`sessions.send`, подписки на `session.message` и `session.operation`).
- Публикация реплик владельца через вебхук канала (имя и аватар автора), автосоздание вебхука.
- Очередь отправки `outbox.js`: воркер на канал, ретраи, парковка буфера, dead-letter, восстановление состояния, правка сообщений.
- Команды из чата: `/status` (с кнопками), `/model`, `/models`, `/modelall`, `/modelprovider`, `/think`, `/ctx`, `/ctxwarn`, `/ctxcompact`, `/compact`, `/stop`, `/notices`, `/toolstyle`, `/toolticker`, `/typing`, `/chatadd`, `/restart`, `/help`.
- Проверка id модели по каталогу перед `sessions.patch` — опечатка больше не ломает сессию.
- Уведомления о вызовах инструментов: стили `code/quote/spoiler/plain/off`, режим тикера (одно сообщение на серию, дописывается через `PATCH`), вырезание ссылок.
- Контекст: плашка по порогам, принудительная компакция, детектор «чат молчит».
- Тикер и плашки переживают порядок очереди; состояние — в `outbox.json`.
- Мультибот: `LOLKA_CFG_SUFFIX` переключает набор файлов (`.token`, `bridges.json`, `.owner.json`, `outbox.json`, лог).
- Ограничение доступа к командам: только владелец (id из `.owner.json`) плюс явный список `LOLKA_ADMINS`.
- `test-outbox.js` — регресс очереди (retry, dead-letter, park/poke, restore, onResult, edit).

### Известные ограничения

- Индикатор набора (`typing`) от ботов Lolka не транслируется — заглушка-no-op на стороне платформы; мост держит вызов на случай включения поддержки.
- Правка сообщений: только `PATCH` (`PUT` → 404).
- Файлы и изображения из сессий пока не доставляются.
