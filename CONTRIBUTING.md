# Как участвовать

## Баг-репорт

Приложите:

1. версию Node и ОС;
2. фрагмент лога с метками `[gw]`, `[lolka]`, `[outbox]`, `[ctx]` (без токенов!);
3. шаги воспроизведения и ожидаемое поведение.

## Pull request

1. Форк → ветка от `main`.
2. `npm install`, затем `npm run test:outbox` — тест очереди должен проходить.
3. `node --check bridge.js` — синтаксис.
4. Без секретов, реальных id каналов/серверов и токенов в коде, тестах и примерах.
5. Запись в `CHANGELOG.md` (раздел «Не выпущено»).

## Стиль

- CommonJS, без сборки, Node 22+.
- Никаких новых зависимостей без обсуждения в issue.
- Сетевые вызовы — через существующие обёртки (`botSend`, `botEdit`, `req`), чтобы сохранялись таймауты и ретраи.
- Новые команды — в `handleCommand` + строка в `/help` + раздел в README.
